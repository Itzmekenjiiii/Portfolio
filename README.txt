KENJI — SHOPIFY VIRTUAL ASSISTANT PORTFOLIO

FILES
- index.html: page structure and content
- style.css: responsive layout and visual design
- script.js: mobile navigation and current year
- assets/profile.jpg: your portrait image (add this after uploading your photo)

OPEN IN VS CODE
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or install the "Live Server" extension and click "Go Live".

CUSTOMIZE BEFORE APPLYING
1. Create an assets folder beside index.html, then place your photo inside it named profile.jpg. A square or portrait JPG works best.
2. Replace the email placeholder below with your real professional email.
3. In index.html, replace YOUR_EMAIL@example.com with your real professional email (search for the placeholder and replace all instances).
4. Add your actual LinkedIn, Upwork, or OnlineJobs.ph profile links if you want.
5. Add screenshots of real practice projects after creating them in Google Sheets or Excel.
6. Keep the work samples labeled as practice/sample projects unless they are real client work.
7. Only claim Shopify, Excel, or customer-support skills you can actually demonstrate. The portfolio currently describes Shopify Admin as a skill you are learning.

This is a static website; no backend or paid service is required.
